The task

The model must propose two distinct routes, validate every cut, and stop only at confirmed stock.

Scoring

          
Partial credit explains. Hard gates decide.

          
The reward measures progress from parseable output to diverse, supported routes. Pass@1 remains stricter.

        


        

          

            R = Σ weight × component
            Each component is scored from 0 to 1.
          

          

          

        


        

          
G
Graph
Is the molecule → reaction → molecule structure connected and well formed?

          
S
Steps
Are the proposed reactions supported, structurally valid, and atom-consistent?

          
$
Stock
Do all terminal leaves exist in the selected inventory after an exact lookup?

          
Δ
Diversity
Do verified routes begin with genuinely different first disconnections?

          
!
Invalid proposals
How often did the agent ask the verifier to check an unsupported or malformed cut?

          
≡
Any exact route
Did at least one submitted tree exactly match any hidden reference route?
