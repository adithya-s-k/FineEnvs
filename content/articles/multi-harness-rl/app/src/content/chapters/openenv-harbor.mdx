## OpenEnv × Harbor

### What is Harbor?

Harbor decouples the task, the harness and the sandbox behind one interface, which is exactly the
decoupling a multi-harness training setup needs, already built.

### Serving Harbor through OpenEnv, for evals and for training

Pick a dataset, pick a sandbox, pick a harness, run a rollout, and get back a trainable trajectory,
or, without token capture, a clean eval.

{/* TODO: the CLI surface, from OpenEnv PR #1036:
      openenv harbor info    , what this machine can actually run; read-only, boots nothing
      openenv harbor rollout , rollouts with no env server; also the debugging path
      openenv harbor serve   , the env server: Task API, run_rollout MCP tool, web UI
      openenv harbor push    , deploy the same server to a Space
    Note that --llm-url is required with no default and no env fallback, because an unset endpoint
    produces rollouts that look completely normal and carry no token ids. */}
