## What to submit

Write a complete, rigorous proof in plain language (Markdown, with LaTeX for formulas) to `/workspace/proof.md`.
If the problem asks for a value or a set of values, state it and prove it. Prove every claim you rely on; a result

is fully justified, none for steps that are only asserted. Only the final contents of `/workspace/proof.md` are
read. Python 3 with sympy is available for checking computations, but the proof itself must not depend on running
code. There is no internet access.
